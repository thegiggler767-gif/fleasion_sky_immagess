# fleasion-skyboxes

Custom skyboxes for Roblox Rivals, used with [Fleasion](https://fleasion.com).

Each folder holds the 7 textures for one skybox:
`SkyboxFt` `SkyboxBk` `SkyboxLf` `SkyboxRt` `SkyboxUp` `SkyboxDn` `SkyboxSideWrap`

## Packs

| Pack | Description |
|---|---|
| `xortyeazy` | True-black star sky with fine specks, large glinting stars, and a tag |

## Using these

Configs use Fleasion's `cdn` mode, so the images are fetched from this repo
and nothing needs copying locally. That works on Windows, macOS and Linux.

The URL must be a **raw** link. A normal `github.com/.../blob/...` link serves
a web page rather than the image and will not work.

```
https://raw.githubusercontent.com/<user>/fleasion-skyboxes/main/xortyeazy/SkyboxFt.png
```

## Installing a config

1. Put the `.json` in Fleasion's configs folder:
   - Windows `%LocalAppData%\FleasionNT\configs`
   - macOS `~/Library/Application Support/FleasionNT/configs`
   - Linux `~/.local/share/FleasionNT/configs`
2. Quit Fleasion **from the system tray** — the X only minimises it.
3. Replacer tab, tick the pack. Only one skybox config at a time.
